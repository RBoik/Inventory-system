# Inventory System - Ready

Flask + SQLite inventory and sales management system.

Features: dashboard, products, categories, suppliers, stock in/out/adjustment, low-stock monitoring, sales, sales history/detail, users, profile and password change.

Default login: `admin` / `admin123`

Run on Windows:
```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Then open http://127.0.0.1:5000

Main styling: `static/css/app.css`.
